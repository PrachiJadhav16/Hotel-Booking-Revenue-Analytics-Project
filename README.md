## Project Overview
This project analyzes hotel booking data to understand booking performance, revenue trends, customer behavior, and booking cancellations.

Excel, SQL, Python, and Power BI are used to prepare, analyze, and visualize the data.

## Project Objectives
- Analyze total bookings and revenue.
- Track monthly revenue trends.
- Compare revenue across cities.
- Analyze bookings by hotel type and booking channel.
- Understand customer booking patterns.
- Analyze booking cancellations.

## Tools & Technologies

### Excel
- Data cleaning and preparation.

### SQL (MySQL)
- Data querying and filtering.
- Aggregate functions such as COUNT(), SUM(), and AVG().
- City-wise revenue and booking analysis.

### Python
- Exploratory Data Analysis (EDA).
- Data manipulation using Pandas and NumPy.
- Data visualization using Matplotlib.

### Power BI
- Interactive dashboard development.
- KPI cards and charts.
- Revenue and booking analysis.
- Interactive filters and slicers.

## Key Performance Indicators
- Total Bookings
- Total Revenue
- Average Booking Revenue
- Cancellation Rate

## Dashboard Features
